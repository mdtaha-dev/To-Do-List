# To-Do List

A simple To-Do List application built using Python and MySQL for managing tasks from the command line.

## Features
- Add, view, update, and delete tasks
- Persistent task storage using a MySQL database

## Requirements
- Python 3.x
- MySQL
- mysql-connector-python

## Run the App

1. Make sure MySQL is running on your system.
2. Update database credentials in `db.py` if required.
3. Install the MySQL connector:
   ```bash
   pip install mysql-connector-python
4. Run the application:python main.py

## Files
- main.py – Application entry point
- tasks.py – Task operations
- db.py – MySQL database connection and queries
